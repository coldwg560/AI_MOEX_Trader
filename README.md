## Описание: Автономный ИИ агент для трейдинга на Московской бирже. Работает через api openrouter с любой моделью. Работает через брокера Т-Инвестиции, соответственно требуется api ключ брокера. Агент обладает кастомизируемой стратегией, которую вы прописываете ему сами. Агент получает базовые данные с индикаторов.


## Как запустить бота

Для запуска графического интерфейса бота (GUI) выполните следующие команды в терминале:

```bash
# 1. Склонируйте репозиторий и перейдите в директорию
git clone https://github.com/your-username/moex_ai_trader.git
cd moex_ai_trader

# 2. Создайте и активируйте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Настройте файл конфигурации .env
cp .env.example .env
# Отредактируйте .env, добавив свои ключи Tinkoff API и OpenRouter API

# 5. Запустите графический интерфейс
python3 gui.py
```

После этого откроется окно приложения, в котором можно управлять настройками и запустить торговый цикл.

## Запуск Терминальной Версии (Для серверов 1 ГБ RAM)

Если вы арендовали слабый VPS сервер (например, 1 ядро, 1 ГБ оперативной памяти) на Ubuntu или Debian, графическая версия (`gui.py`) неизбежно вызовет нехватку памяти (Out-Of-Memory Error) из-за тяжелого WebKit/Tkinter движка. 

В таком случае используйте оптимизированную TUI версию.
